Os três modos devolvem o mesmo resultado. Use o que você tem em mãos.

Aparece como /auth?eat=.... O token é enviado por POST e mostrado mascarado.

As claims são lidas localmente: UID, nome, região e validade. A assinatura não é verificada.

A senha nunca volta na resposta e não é salva. Ela só vai na requisição para a Garena.

Para quem programa

Mesma lógica, uma rota. GET com parâmetros ou POST com JSON — o que for mais cômodo.

01
Access token/auth?eat=TOKEN
02
JWT direto/auth?jwt=TOKEN
03
UID + senha/auth?uid=ID&pass=SENHA
